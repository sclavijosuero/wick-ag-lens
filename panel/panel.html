WICK-AG-Lens: Accessibility Inspector v2.0.0

This tab strictly isolates actionable failures, critical accessibility errors, and severe anti-patterns.

This tab provides an exploratory audit of valid page architecture, semantic landmarks, structural maps, and proper accessibility patterns.

  • Visibility Filtering: Elements hidden via display: none, visibility: hidden, hidden, or inert are strictly excluded from all analysis to match native accessibility tree behavior.
  • Visual Occlusion: Visibility calculations rely on CSS properties. The tool does not calculate 3D geometric occlusion (e.g., an element technically "visible" in CSS but visually covered by a high z-index modal).
  • Focus Order: Mirrors standard browser Tab execution, prioritizing tabindex > 0, respecting native Radio Group bundling, and ignoring disabled/hidden nodes.
  • Shadow DOMs: Standard (open) Web Components are fully traversed and supported. Explicitly 'closed' Shadow Roots remain inaccessible by browser design.
  • Iframes & Cross-Origin Policies: Due to strict browser security (Same-Origin Policy), the inspector cannot pierce or audit the internal DOM of cross-origin iframes (e.g., embedded videos or third-party widgets).
  • Color Contrast Heuristics: Contrast ratios are calculated using computed DOM styles. Complex backgrounds (images, gradients) or mixed element opacities may reduce accuracy compared to pixel-level visual analysis.

Disclaimer: WICK-AG-Lens is an automated heuristic tool implemented to the best knowledge of its author. It does not cover all possible accessibility barriers that may exist on a page, and existing audits may occasionally yield false positives or false negatives. Passing these checks does not guarantee full WCAG compliance. Automated testing should always be combined with manual testing and assistive technology validation.
