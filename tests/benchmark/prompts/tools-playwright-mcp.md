Approach B: the Playwright MCP tools.
- Browsing and scouting (signing in, learning the selectors, seeing what each action reveals): ONLY the Playwright MCP tools (`mcp__playwright__browser_navigate`, `browser_snapshot`, `browser_click`, `browser_type`, `browser_fill_form`, `browser_hover`, `browser_press_key`, `browser_select_option`, `browser_wait_for`, `browser_evaluate`, `browser_close`, ...). They are deferred tools: load their schemas first with ToolSearch (for example the query `select:mcp__playwright__browser_navigate,mcp__playwright__browser_snapshot,mcp__playwright__browser_click,mcp__playwright__browser_type,mcp__playwright__browser_fill_form,mcp__playwright__browser_hover,mcp__playwright__browser_press_key,mcp__playwright__browser_select_option,mcp__playwright__browser_wait_for,mcp__playwright__browser_close`). Do not use the agent-browser CLI.
- Handing the login to wick-ag-lens: the Playwright MCP browser cannot export its session to a file, so give wick-ag-lens the sign-in page and the credentials: `--login-url {BASE_URL}/bench-login.html -u jdoe -p Admin+123`.
- Close the Playwright MCP browser when done (`browser_close`).
